How to Use

Practice Pete Trimmer's drills on court:

  1. Filter by category if you want to focus on a skill
  2. Start Drill - get a random drill (unpracticed prioritized)
  3. Set up the balls/position on court as described
  4. Execute the steps, focusing on the key points
  5. Record a score if the drill has a target
  6. Mark Practiced to log this session

Categories:

  • Rushing - rush accuracy and distance
  • Croquet Strokes - angle, ratio, power
  • Hoop Running - controlled hoop play
  • Combination - multi-skill routines
  • Tactical - decision-making exercises
  • Mental - pressure and consistency

Progress: Badge shows unique drills practiced out of 22 total.

Install on Android:

  1. Open in Chrome
  2. Tap ⋮ menu (top right)
  3. Tap "Add to Home screen"

Works offline after first load.

Source: Pete Trimmer, Beyond Expert Croquet Ch. 11 (pp. 189-209)
